# Contents

This folder contains results from scaffolding and annotating the genome found at: https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_041430235.2/
Note that NCBI updates headers as part of the submission process, so that Scaffold 1 = chromosome 1

## braker.codingseq.primary_physalia_scaffolds_v0.4.fasta.zip

Braker annotation, codingseq fasts file 

## braker.aa.primary_physalia_scaffolds_v0.4.fasta.zip

Braker annotation, aa fasta file

## braker.primary_physalia_scaffolds_v0.4.gtf.zip

Braker annotation gtf

## repeat.primary_physalia_scaffolds_v0.4.gff.zip

Repeat annotation gff

## primary_physalia_scaffolds_v0.4.modified.headers.fasta.masked.fai

Index file for masked genome

## plot_genome_stats.r

Script for generating visualization on scaffolding and annotation
